# 얼불춤 커스텀 로더 — UI/UX 구현 지침

근거: 사용자가 2026-11-23 제공한 가로화면 스크린샷 2장, 정품 게임 3.3.1의 로컬 역컴파일 자료 `PauseMenu.cs`, `SettingsMenu.cs`, 기존 로더 `overlay.cpp`. *별도의 원본 그래픽 파일이나 저작권이 있는 이미지를 외부로 복제하지 않는다.*

## 원본 UI에서 확인한 설계 규칙

1. **행성과 궤도 중심 시각 언어.** 화면 제목 근처에 따뜻한 붉은 행성과 청록색 행성, 얇은 원형 궤도. 게임 월드의 시각 정체성만 코드로 재현한다. 실제 원본 Unity 패널이 필요할 때는 `PauseMenu.ShowSettingsMenu()`를 호출한다.
2. **짧은 조작 면적.** 원본 `PauseMenu.cs`는 `pauseButtonWidth = 52f`, 버튼 간격 58f 등의 설계 상수를 갖고 있다. 픽셀 단위 단순 복사 대신 화면 비율에 맞게 스케일하되, 1536픽셀 가로화면에 1400픽셀 버튼을 놓는 배치는 지양한다.
3. **설정 화면은 원본 것을 사용.** `PauseMenu`는 설정 탭에서 `CanvasScaler.referenceResolution`을 425×198 가상 좌표로, 나머지는 352×198로 바꾼다. 원본 `SettingsMenu.cs`에 `mobileResolution`, `visualEffects`, `visualQuality`, `targetFrameRateMobile` 처리가 존재한다. 로더가 이를 중복 구현할 필요는 없다.
4. **완료 상태와 선택 상태를 구분.** 이펙트 토글은 설정 영구 적용 여부를 표시하고, 현재 지도만 반영하는 실행 제어와 혼동하지 않는다. 원본 입력·판정과 무관한 시각화만 변경한다.

## 사용자 스크린샷에서 발견한 문제

- 최근 맵 4개만으로 스크린 하단에 설정/저장 공간 버튼이 내려간다. 0개일 때는 아래 버튼이 위로 이동한다. 즉, 최근 맵과 나머지 제어의 위치가 사용자 데이터 개수에 종속된다.
- 전체 폭 버튼 1400픽셀 내외는 선택 대상이 작아도 가로로 길게 뻗어 사용성이 떨어진다.
- UI 구조는 텍스트·긴 사각형 버튼·행 사이 구분선 위주이고, 원본의 행성/궤도·컴팩트한 조작 언어가 헤더 외에는 부족하다.
- 오류 문자열 `Calibration API mismatch`가 노출된다. 보정 기능은 임의로 건너뛰지 말고 실제 API 검사 후 실패 시 원본 보정화면으로 복구한다.

## 구현 지침

- **고정된 컨텐츠 최대 너비:** 화면 중앙의 관리 패널을 논리적인 최대 너비로 제한하고, 작은 기기에서는 화면 폭에 유연하게 맞춘다.
- **최근 맵 내부 스크롤:** 최근 맵 목록은 일정 높이 이내에서만 커지며 항목이 많아지면 그 영역 안에서 스크롤한다. 아래 주 제어는 화면 하단에 그대로 보이도록 한다.
- **짧은 버튼과 2열 구성:** `설정`, `저장 공간` 같은 짧은 동작은 같은 줄에 나란히 배치. `파일 열기`는 대표 버튼으로 한 줄만 사용하되 전체 화면 폭을 사용하지 않는다.
- **세 가지 비주얼 단계:** `기본`(원본 그래픽), `자동 최소화`(원본 VisualEffects.Minimum), `타일+음악만`(이펙트·배경·장식 렌더만 억제하고 타일·행성·판정·음악 보존). 강한 단계가 약한 단계에 우선하며 게임 플레이 중에만 작동한다.
- **모바일 터치:** 좁은 높이에서도 44–52dp 상당의 터치 타깃을 유지하고, 이미 사용 중인 ImGui 입력 라우팅을 손상시키지 않는다.
- **폰트:** 현재 폰트 로딩/한국어 폴백은 그대로 사용. 외부 폰트를 재배포하지 않는다.
- **검증:** 최근 맵 0·1·4·20개, 가로/세로, 설정/스토리지 화면, 파일 선택/다중 ZIP, Pause/Resume, 원본 해상도/게임 설정으로의 전환, 이펙트 토글 ON/OFF에서 시각·소리·판정이 일관적이어야 한다.

## 경계

게임과 동일한 입력 판정 또는 타이밍을 만들기 위해 게임 내부 동작을 재작성하지 않는다. 원본 설정 UI를 이미 호출하는 경로가 있으므로, 그 패널은 복제하는 대신 그대로 사용한다. 외부 앱에 원본 이미지·에셋을 묶지 않는다.
