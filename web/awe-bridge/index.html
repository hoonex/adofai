레벨 검색해서 바로 플레이하기

첫 번째로 알려준 Web ADOFAI는 레벨 검색만 하는 목록이 아닙니다. 검색한 레벨을 브라우저에서 실행할 수 있는 웹 플레이어를 포함합니다. 기존 안내가 잘못되었습니다.

Web ADOFAI · 레벨 검색 + 브라우저 플레이

커뮤니티 레벨을 검색해 선택하고 브라우저에서 플레이할 수 있습니다. 편집기보다는 플레이어 기능에 초점을 맞춘 사이트이며, 원본 PC 게임의 Unity 실행 파일을 그대로 돌리는 것은 아닙니다.

AWE · 레벨 제작 및 편집

차트를 새로 만들거나 .adofai를 수정할 때 쓰는 별도 커뮤니티 웹 에디터입니다. Three.js 기반 맵 렌더링과 이벤트 편집·미리보기를 제공합니다. 제작: Ssimille 및 기여자들.

파일 준비 완료

차트 파일음악 파일

차트와 음악을 각각 저장한 다음 AWE 에디터 열기 → Level Settings → Load Level에서 두 파일을 동시에 선택하세요. AWE는 ZIP 직접 가져오기를 지원한다고 확인되지 않았습니다.
